# Chapter 1: Computer Systems
## Exercises 
[[livro-ECS-2ndEDITION-corrected.pdf#page=23&selection=6,0,6,9|livro-ECS-2ndEDITION-corrected, page 23]] 
1.1 
	a) Compiler: A programs which translates high-level language code into machine code (or assembly language). 
	b) Interpreter: A program that reads, translates, and executes the source code statement by statement (instruction by instruction) immediately during runtime. 
	c) Virtual machine: A software emulation of a computer system that behaves like a physical computer.
1.2 
	The ratio is 1 line of high-order language code to n lines of machine code, where n is greater than 1 because the line written in high-order language code is basically decomposed into multiple tiny steps in order for the computer to understand better the task.
1.3
	| Memory cell | Binary |
	| ----------- | ------        |
	| 132,104 |    `00010010`    |
	|132,105 |     `00110100`   |
	|132,106 |      `01010110`  |
	|132,107 |    `01111000`    |

	| **132,106** | `00110100` |

1.5 
	To the stored-program computer, instructions look exactly like data (they are just patterns of bits). Therefore, a program can treat its own instructions as if they were data and modify them while it is running. This is called self-modifying code.
